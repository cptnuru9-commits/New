# SiteLens — ניתוח אתר לאדריכלות

אתר לניתוח אתר אדריכלי לכל כתובת בישראל, על מפה אינטראקטיבית — בנוי סביב הנושאים של עבודת ניתוח אתר בלימודי אדריכלות.
מקלידים כתובת (או לוחצים על המפה / "גוש X חלקה Y" / קואורדינטות WGS84 או ITM), וכל לשונית מציגה נושא אחד — **והמפה מתחלפת בהתאם**, עם מקרא שמסביר כל סימון ומציג את הנתונים עצמם.

| לשונית | מה מוצג | במפה |
|---|---|---|
| **סיכום** | כרטיסי נתונים, SWOT אוטומטי, מפת נושאים, הערות אישיות | חלקה, טווחי הליכה, תחב״צ, ירוק |
| **מגרש** | גוש/חלקה, גבול המגרש, מידות הצלעות, חזית לרחוב, קווי בניין ושטח בנייה (מרווחים ניתנים לעריכה) | מידות על כל צלע, חזית, מעטפת בנייה |
| **תכנון** | תב״ע החלות, תכניות בסביבה, ייעודי קרקע ושצ״פ, היתרים (ת״א), מסמכים לאסוף | קווים כחולים, ייעודים בצבעי מבא״ת |
| **טופוגרפיה** | גובה, שיפוע ממוצע, מפנה, שטח תלול, חתכים A–A׳ / B–B׳, קו החוף ונחלים | צבעי גבהים + הצללה, קווי גובה עם ערכים, נקודות גובה, קווי חתך |
| **אקלים** | מסלול שמש, שושנת רוחות, טמפרטורות ומשקעים, המלצות תכנון | כיווני זריחה/שקיעה, חץ רוח שולטת |
| **תנועה** | תחב״צ וקווים, דרכים ומחלפים, אופניים, טווחי הליכה, אומדן רעש | תחנות, דרכים, מסילות, שבילים, איזוכרונים |
| **שירותים** | ציון נגישות, חינוך, ירוק, בריאות, קהילה, מסחר | אייקונים לפי קטגוריה |
| **מרקם** | תכסית, קומות, רח״ק משוער, התפלגות גובה, מורשת ושימור | מפת דמות-רקע / גובה מבנים |
| **אוכלוסייה** | התפלגות גילאים באזור הסטטיסטי (מפקד 2022), נתוני היישוב | גבול האזור הסטטיסטי |
| **מקורות** | מצב כל מקור + "נסו שוב", הגדרות, ניקוי מטמון | — |

**ייצוא:** העתקת סיכום, GeoJSON (חלקה, מעטפת, תכניות, ייעודים, שירותים, קווי גובה ומבנים — ל-QGIS / ArcGIS / Rhino), והדפסה / PDF.

## עמידות לשרתים איטיים

- כל בקשה עם הגבלת זמן ו**ניסיון חוזר אוטומטי** (429 / 5xx / ניתוק).
- Overpass: **בקשות מגודרות** — אם שרת לא עונה תוך 6 שניות נשלחת אותה בקשה לשרת גיבוי, והראשון שעונה מנצח.
- שאילתות כבדות מחולקות לחלקים קטנים שרצים במקביל (מים / תנועה / מבנים / שימושי קרקע).
- **מטמון קבוע (IndexedDB)** — ביקור חוזר באותה כתובת נטען מיד.
- כל מקור עצמאי: אם אחד נכשל, השאר ממשיכים, ובכרטיס מופיע כפתור **"נסו שוב"**.
- שירותי ArcGIS ממשלתיים: fetch → פרוקסי (אם הוגדר) → JSONP.

## הפעלה

אתר סטטי, בלי בנייה:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

או GitHub Pages (Settings → Pages → Deploy from branch).

## מקורות

OpenStreetMap (Nominatim, Photon, Overpass), OpenFreeMap (מפת בסיס), GovMap / המרכז למיפוי ישראל, מנהל התכנון (XPLAN), הלמ״ס ו-data.gov.il, Wikidata, Open-Meteo (ERA5, Copernicus DEM), AWS Terrain Tiles (SRTM), Valhalla, SunCalc.

המידע מיועד ללימוד ולניתוח ראשוני. מידע תכנוני מחייב יש לאמת מול הוועדה המקומית ומבא״ת.

## מבנה

```
index.html         מבנה הדף
css/styles.css     עיצוב (בהיר/כהה, רספונסיבי, הדפסה)
js/config.js       כתובות מקורות המידע (ניתנות לעריכה מהאתר)
js/utils.js        רשת עמידה, מטמון, ITM, גיאומטריה
js/api.js          שליפת הנתונים מכל המקורות
js/contours.js     קווי גובה, צבעי גבהים, חתכים
js/plot.js         גבול מגרש, חזית, קווי בניין
js/demography.js   גילאים לפי אזור סטטיסטי
js/charts.js       גרפים: שמש, רוח, אקלים, אוכלוסייה, חתך
js/map.js          מפה, שכבות לפי נושא, תוויות
js/render.js       תוכן הלשוניות והמקרא
js/app.js          חיפוש, טעינה, אינטראקציה, ייצוא
```

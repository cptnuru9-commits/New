# MLBB Meta — אפליקציית ווב ל-Mobile Legends: Bang Bang

- **טיר ליסט** לפי ווין רייט, פיק רייט, באן רייט או ציון משוקלל, עם סינון לפי ליין, דרגה ותקופה.
- **דף דמות:** קאונטרים, מול מי היא חזקה, סינרגיות, קאונטרים ושותפים מהנתונים החיים, ובילד מומלץ לכל ליין (פריטים, אמבלם, ספל).
- **בונה קבוצה:** ניתוח הרכב והמלצות לכל ליין פנוי לפי סינרגיה עם הקבוצה, קאונטר ליריבים וביצועים חיים.

## מקורות
- **סטטיסטיקה חיה:** נתוני הדירוג הרשמיים של Moonton דרך ה-API הקהילתי `mlbb-stats.ridwaanhall.com`. הדפדפן טוען אותם ישירות.
- **הערכת מטא (Season 42, Patch 2.2.16a):** הסכמה בין mlbbhub, timesaver, mlbbdex ו-elitedias. הרשימה ב-`META_INFO` בקובץ `js/heroes.js`.
- **קאונטרים, סינרגיות ובילדים:** מאגר ערוך ב-`js/heroes.js` וב-`js/builds.js`. הוא לא מתעדכן לבד.

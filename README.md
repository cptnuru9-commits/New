# SiteLens — ניתוח אתר לאדריכלות

אתר לניתוח אתר אדריכלי לכל כתובת בישראל, על מפה אינטראקטיבית.
מקלידים כתובת (או לוחצים על המפה / "גוש X חלקה Y" / קואורדינטות WGS84 או ITM) ומקבלים:

| לשונית | מה מוצג | מקור |
|---|---|---|
| **סקירה** | כרטיסי KPI, ציון נגישות לשירותים, צ׳קליסט ניתוח אתר | כל המקורות |
| **תכנון** | גוש, חלקה, שטח רשום · תב״ע החלות על האתר (מספר, סטטוס, ייעוד, קישור למסמכים) · תכניות בסביבה · היתרי בנייה (ת״א) · רשימת מסמכים לאסוף | GovMap opendata (המרכז למיפוי ישראל), מנהל התכנון XPLAN, GIS ת״א |
| **תחבורה** | תחנות אוטובוס וקווים, רכבת ורק״ל, דרכים עיקריות ומחלפים, איזוכרוני הליכה 5/10/15 דק׳ | OpenStreetMap (Overpass), Valhalla |
| **שירותים** | חינוך, גנים ופארקים (כולל שטח ירוק), בריאות, ציבור וקהילה, מסחר, חניונים | OpenStreetMap |
| **אוכלוסייה** | תושבים, שטח, צפיפות, קצב גידול וגרף לאורך שנים · מרקם בנוי: תכסית, קומות, רח״ק משוער | למ״ס דרך Wikidata, data.gov.il, OSM |
| **סביבה** | מרחק מקו החוף (תחום 100/300 מ׳), נחלים וגופי מים, גובה ושיפוע, מסלול השמש, שושנת רוחות, אקלים חודשי | OSM, Open-Meteo (Copernicus DEM, ERA5), SunCalc |
| **מקורות** | סטטוס כל מקור, קישורים ל-GovMap, מבא״ת, למ״ס, nadlan ועוד | — |

שכבות מפה: קווים כחולים של מנהל התכנון, גושים וחלקות של GovMap, גובה מבנים, פארקים, מים וקו חוף, דרכים, כיווני זריחה/שקיעה, תצלום אוויר.

ייצוא: העתקת סיכום, הורדת GeoJSON (לפתיחה ב-QGIS / ArcGIS), והדפסה / שמירה כ-PDF.

## הפעלה

אתר סטטי, בלי צורך בבנייה או בהתקנה:

```bash
python3 -m http.server 8000
# ואז לפתוח http://localhost:8000
```

אפשר גם לפרסם ב-GitHub Pages (Settings → Pages → Deploy from branch).

## הערות

- **שירותים ממשלתיים** (GovMap, מנהל התכנון, data.gov.il) משנים מדי פעם כתובות או חוסמים בקשות מהדפדפן (CORS). בכל מקור יש גיבוי (JSONP, שרתי Overpass חלופיים, מעגלי הליכה) וקישור ישיר ל-GovMap / מבא״ת. בחלון **הגדרות** (⚙️) אפשר לעדכן כתובות API ולהגדיר פרוקסי CORS.
- ה-API הרשמי של GovMap דורש טוקן; האתר משתמש בשכבות הפתוחות (opendata) ובקישורים עמוקים.
- המידע מיועד ללימוד ולניתוח ראשוני בלבד. מידע תכנוני מחייב צריך לאמת מול הוועדה המקומית ומבא״ת.

## מבנה

```
index.html        מבנה הדף
css/styles.css    עיצוב (בהיר/כהה, רספונסיבי, הדפסה)
js/config.js      כתובות מקורות המידע
js/utils.js       רשת, המרת ITM, גיאומטריה, עיצוב מספרים
js/api.js         שליפת הנתונים מכל המקורות
js/charts.js      גרפי SVG: שמש, רוח, אקלים, אוכלוסייה
js/map.js         מפת Leaflet ושכבות
js/render.js      תוכן הלשוניות
js/app.js         חיפוש, תזמור, אינטראקציה
```
